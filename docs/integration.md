# Registry — Integrations

| Direction | Counterpart | Protocol | Purpose | Configuration key | Evidence path/symbol |
|---|---|---|---|---|---|
| provided | Host Spring Boot application (in-process) | Java service API (`ResourceService`, `ResourceTypeService`, `SearchService`, `VersionService`, ...) | Store, validate, version and search resources | `registry.*` | `registry-starter-service/.../autoconfigure/RegistryServiceAutoConfiguration.java` |
| provided | HTTP clients, `registry-starter-client` | REST JSON/XML | Same over HTTP. Dump/restore, ResourceSync | host's `server.*` | `registry-core-rest/.../controllers/*` |
| provided | JMS subscribers | JMS topics `{prefix}.{resourceType}.{create,update,delete}`, JSON text messages, type id property `_type` | Resource change notifications | `registry.jms.prefix` (default `registry`) | `registry-starter-jms/.../jms/JmsResourceListener.java` |
| consumed | PostgreSQL | JDBC/JPA (HikariCP), Flyway | Primary storage | `registry.datasource.*`, `registry.jpa.*`, `spring.flyway.*` | `configuration/HibernateConfiguration.java` |
| consumed | Elasticsearch 7.x | HTTP (High Level REST Client), basic auth when a username is set | Indexing, keyword/vector search, recommendations, startup reconciliation | `registry.elasticsearch.uris[0]`, `.username`, `.password`, `.enabled`, `elastic.*` | `registry-starter-elasticsearch/.../ElasticAutoConfiguration.java#restHighLevelClient` |
| consumed | ActiveMQ (Classic) broker | OpenWire through `ActiveMQConnectionFactory` | Publish change events | `registry.jms.host` (default `tcp://localhost:61616`), `.username`, `.password`, `.enabled` | `JmsAutoConfiguration.ConfigureJms#activeMQConnectionFactory` |
| consumed (client starter) | Remote registry | HTTP REST through `RestTemplate` | Client-side service implementations | `registry.base` | `registry-starter-client/.../client/*ServiceImpl.java` |
| consumed | Embedding model files (Spring AI transformers, ONNX) | Downloaded by Spring AI from its GitHub repository at startup unless cached under `java.io.tmpdir` | Compute 384-dim embeddings | `spring.ai.embedding.transformer.*` | `registry-starter-service/pom.xml`, `WeightingEmbeddingService` |

## Provided interfaces

- REST: [api.md](api.md). The OpenAPI document is generated by springdoc at runtime.
- JMS payloads: `registry-core-api/.../domain/jms/ResourceJmsCreated`, `ResourceJmsUpdated` (new and
  previous resource), `ResourceJmsDeleted`. Messages are serialised with
  `MappingJackson2MessageConverter` (ISO-8601 dates `yyyy-MM-dd'T'HH:mm:ss.SSSXXX`).
- Resource-type additions and deletions are **not** published to JMS (they're logged as `WARN`).
 (`JmsResourceListener#resourceTypeAdded/#resourceTypeDelete`)
- A resource type change is published as `delete` on the old type plus `create` on the new type. The
  delete payload carries the new resource (code `FIXME`).

## Failure behaviour

| Situation | Behaviour | Evidence |
|---|---|---|
| Elasticsearch, JMS or version listener throws after a DB change | Logged at `ERROR` (`Error notifying listener`). The DB change stands, so the index and subscribers drift | `monitor/ResourceMonitor` |
| Elasticsearch out of sync | Reconciled on next startup (`IndexDbSync`): DB→index re-adds. Index-only entries are only logged | `IndexDbSync#ensureDatabaseIndexConsistency` |
| Missing Elasticsearch index during reconciliation | The index is created from the resource type. Up to 5 attempts | `IndexDbSync#fetchResourceIdsFromIndex` |
| JMS broker unavailable | `JmsTemplate.convertAndSend` fails per event and is logged. Events aren't persisted or retried, so they're lost | `JmsResourceListener`, `ResourceMonitor` |
| Restore of a broken item | Skipped (`AlwaysSkipItemSkipPolicy`) | `BackupRestoreConfig#resourcesStep` |
| Dump read errors | Retried indefinitely (`AlwaysRetryPolicy`) and skipped on write errors | `BackupRestoreConfig#resourcesDumpStep` |
| Client starter timeouts | Plain `new RestTemplate()` instances in most clients, so no timeouts | `registry-starter-client/.../client/*` |
| Elasticsearch client timeouts | Client library defaults. Only the first URI in `registry.elasticsearch.uris` is used | `ElasticAutoConfiguration#restHighLevelClient` |
