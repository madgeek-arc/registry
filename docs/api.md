# Registry — API

The REST controllers live in `registry-core-rest`. `registry-starter-service` registers them in
every web application that embeds it, including `registry-service`, unless
`registry.rest.enabled=false`. (`RegistryRestControllersConfiguration`,
`RestControllersEnabledByDefaultIntegrationTest`, `RestControllersDisabledIntegrationTest`)

| Item | Value |
|---|---|
| Base URL | `http(s)://<host>:<port><context-path>`. The repository sets no port or context path (Spring Boot defaults `8080`, `/`) |
| Versioning | None in paths |
| Authentication | **None**. The consuming application guards the paths (see [security.md](security.md)) |
| OpenAPI | Generated by springdoc: `/v3/api-docs`. Swagger UI `/swagger-ui.html` in `registry-service` (which adds `springdoc-openapi-starter-webmvc-ui`) |
| Formats | JSON, plus XML for schemas and ResourceSync. Errors are RFC 7807 `application/problem+json` |

## Endpoint groups

Routes come from `registry-core-rest/src/main/java/gr/uoa/di/madgik/registry/controllers/`. This
is a summary. The generated OpenAPI is the authoritative reference.

| Group | Base path | Purpose | Controller |
|---|---|---|---|
| Typed records | `/records/{resourceType}` (`/{id}`, `/key`, `/semantic`, `/hybrid`, `/highlighted`, `/hybrid/highlighted`, `/{id}/versions`, `/{id}/recommendations`, ...) | CRUD and search addressed by the type's primary-key fields. `registry.rest.typed-resources-controller.enabled=false` removes it alone | `TypedResourceController` |
| Resources | `/resources` | CRUD, paging (`from`, `to`), indexed-field view, change type | `ResourceController` |
| Resource types | `/resourceType` | CRUD and index-field definitions | `ResourceTypeController` |
| Search | `/search/{name}` (`/semantic`, `/hybrid`, `/highlighted`, `/hybrid/highlighted`, `/recommendations`), `/search/cql/{resourceType}` | Faceted/keyword, semantic and hybrid search, recommendations, CQL queries | `SearchController` |
| Versions | `/version` | Version history per type, resource or version | `VersionController` |
| Schemas | `/schemaService/{id}` | Schema document (XML) | `SchemaController` |
| Dump | `GET /dump/` (`raw`, `schema`, `version`, `resourceTypes`) | Export as ZIP | `DumpController` |
| Restore | `POST /restore/` (multipart `datafile`) | Import a ZIP via Spring Batch | `RestoreController` |
| ResourceSync | `/resourcesync/`, `/resourcesync/{name}/resourcelist.xml`, `/resourcesync/{resourceType}/{date}/changelist.xml` | ResourceSync capability, resource and change lists | `ResourceSyncController` |

## Errors

`GlobalExceptionHandler` (lowest precedence, so a host's own `@ControllerAdvice` with a higher
`@Order` wins) maps exceptions to problem details. (`GlobalExceptionHandlerTest`)

| Exception | Status |
|---|---|
| `ResourceNotFoundException` | 404 |
| `ResourceAlreadyExistsException` | 409 |
| `UnsupportedSearchParameterException`, `ServiceException` | 400 |
| `MissingResourceEmbeddingsException` | 422 |
| `ResourceException` | its own status |
| Spring MVC errors (unknown path, unsupported method or media type, missing parameter, `ResponseStatusException`) | their own status (404, 405, 415, 400, ...) |
| Anything else | 500, with a generic message. The exception is logged at `ERROR` |

The handler is registered in every host that embeds the service starter, also when
`registry.rest.enabled=false`.

## Conventions

- Several mappings match on `headers = "Accept=application/json"` (or XML), so clients must send
  exactly that `Accept` header. Others get 404. (`ResourceTypeController`,
  `VersionController`, `ResourceSyncController`)
- The ResourceSync URLs start with `registry.host` when it is set. Otherwise they use the scheme,
  host, port and context path of the current request. Behind a proxy, set `registry.host` or
  `server.forward-headers-strategy`. (`ResourceSyncServiceImpl`, `ResourceSyncServiceImplTest`,
  checked live with `registry-service`)
- Actuator: `spring-boot-starter-actuator` is a dependency of `registry-starter-service`, so
  `/actuator/health` is exposed over HTTP (Spring Boot's default exposure) unless the host changes it.
